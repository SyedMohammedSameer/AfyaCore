# AfyaCore demo video

The ML4H demo video, rendered with [Remotion](https://remotion.dev) from frames
of the running application.

## The rule

**Every frame of AfyaCore in this video is a photograph of the running app.**
Nothing is a mockup, a Figma export, or a React re-creation of the interface.
Remotion never draws the product — it arranges, captions and animates frames the
app itself produced. A demo for a track that asks for an operational end-to-end
demonstration should not contain a pixel the software cannot produce on demand.

Two sources, both real:

- `docs/screenshots/*.webp`, regenerated by `npm run screenshots` against the
  production build. Reused rather than re-captured, so the video and the README
  can never drift apart.
- A live sequence captured by `capture.mjs` with the browser's network switched
  off — the one thing a still cannot show. It is the same walk `npm run smoke`
  asserts in CI, so the video cannot show something CI does not also prove.

The only things drawn in React are the title cards and the results table, which
are text and numbers rather than interface. Every number in the table is
reproducible with `npm run eval`.

## Rendering

```bash
# from the repo root
npm run build && npm run preview     # the app the video photographs

# here
npm install
npm run capture                      # collect real frames into public/
npm run render                       # -> out/afyacore-demo.mp4
npm run studio                       # interactive editor
```

On Linux, Remotion needs an old-headless-capable binary:

```bash
npx remotion render src/index.ts Demo out/afyacore-demo.mp4 \
  --browser-executable=/path/to/chrome-headless-shell
```

Remotion is **not** MIT. It is free for individuals, non-profits, and for-profit
companies with up to three employees, and requires a paid company licence above
that — see `node_modules/remotion/LICENSE.md`.

This is why the video lives in its own package with its own `node_modules`:
AfyaCore itself stays MIT with no Remotion in its dependency tree, and nobody
cloning the app inherits an obligation that belongs to the video tooling.
