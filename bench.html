On-device speech benchmark

Times the AfyaCore speech model (Whisper base, int8, single-threaded WebAssembly) on this device: how long it takes to load, how fast it transcribes, and how much memory it uses. Nothing is recorded from the microphone; it runs on bundled sample audio.

Run

Plug the phone in, close other apps, and keep this tab in front with the screen on. The first run downloads about 80 MB. On a low-end phone a full run can take ten minutes.
