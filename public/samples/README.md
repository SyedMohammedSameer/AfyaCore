# Synthetic demonstration recordings

`studio-fr.wav` and `studio-en.wav` are synthetic speech, generated by
`scripts/studio-samples.mjs` from the first explicitly annotated case in each
`eval/corpus/extraction.*.json` file. `studio-manifest.json` records the case,
reference, voice, speaking rate and SHA-256 of each WAV.

Regenerate with `npm run samples:studio` on macOS. The Thomas and Daniel voices
must be available. If speech synthesis is sandboxed and returns only a header,
the generator fails rather than recording a successful fixture.

The Studio uses the audio as model input. It does not embed a prerecorded model
answer. These are development fixtures, not held-out speech or clinical data.
The existing `dictation-*.m4a` recordings are retained for the capture screen.
